# Bộ bài chung (Shared Decks)

Thư mục này chứa các bộ bài chung mà mọi người dùng TarotDesk đều thấy trong app.

- Mỗi bộ bài là MỘT file JSON với cấu trúc `{"deck": {...}, "cards": [...]}`.
- Chỉ chủ sở hữu (Neito112) mới đưa bộ bài vào đây — bằng màn hình quản trị trong app, hoặc bằng cách merge Pull Request.
- Người dùng sao chép bộ bài chung về thư viện của mình từ trong app. Không sửa trực tiếp các file trong thư mục này.

Không đặt token hay thông tin bí mật vào thư mục này.
